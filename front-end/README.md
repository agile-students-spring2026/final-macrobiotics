# Front-End Setup (React)

This directory contains a React-only frontend scaffold for Sprint 1.

## Included

- React app bootstrapped with Vite.
- Seven screen components matching the wireframe flow:
  - Intro
  - Login
  - Search Results
  - Search Detail
  - Bookmarks
  - Settings
  - History
- Responsive base layout for mobile and desktop.
- Shared top-level navigation to switch among all seven screens.

## Run Locally

1. Open a terminal in `front-end`.
2. Install dependencies:

```bash
npm install
```

3. Start dev server:

```bash
npm run dev
```

4. Build production bundle:

```bash
npm run build
```

5. Preview production build:

```bash
npm run preview
```

## Notes

- All components are function components using JSX.
- No third-party React UI/state/router frameworks are used in app code.
- Current pages are intentionally placeholders so the team can fill real UI and behavior in later tasks.
