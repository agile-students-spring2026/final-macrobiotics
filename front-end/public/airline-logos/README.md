Store airline logo assets in this folder using the airline's primary 2-letter IATA code.

Naming scheme:
- `AA.svg` for American Airlines
- `AS.svg` for Alaska Airlines
- `B6.svg` for JetBlue
- `DL.svg` for Delta Air Lines

Rules:
- Use uppercase airline codes.
- Prefer `.svg` files.
- One file per airline code.
- The app resolves logos at `/airline-logos/<CODE>.svg`.

Examples:
- `/airline-logos/AA.svg`
- `/airline-logos/AS.svg`
- `/airline-logos/B6.svg`
- `/airline-logos/DL.svg`
